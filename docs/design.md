# 全球 AI 每日情报系统

依据用户提供的 V2 实施要求，在空目录搭建 Python 项目。原聊天引用未包含 daily_research.md；未取得正文前编写明确标注的替代研究编辑提示词，之后可直接替换。

## 已确定设计

GitHub Actions 在 Asia/Singapore 09:00 和 10:17 执行同一幂等任务。日报窗口固定为前一天 09:00（含）至报告日 09:00（不含），延迟执行不会改变窗口。采集器通过配置读取 RSS、JSON API、官方发布页以及 Responses Web Search。所有网页、候选与历史内容仅作为不可信数据。

一般新闻由 gpt-5.4-mini 筛选并结构化编辑；重大新闻由 gpt-5.4 二次编辑和核验。来源覆盖、原文时间、链接、模型结构、事实支持和事件进展经过校验后才发布。允许分类无新闻；不得补造。程序保存少量摘要和元数据，不归档全文。

状态保存在 state/events.json；URL 与事件身份、进展指纹共同去重。稳定日报、JSON、事件状态及首页采用可恢复发布事务；历史文件存在时先核验完整性再跳过。失败仅保存诊断、费用与有限文本，不发布日报。

独立 Jinja2 HTML 内嵌样式和交互，支持 file://、深色模式、搜索、分类和移动端。GitHub Actions 自动提交成功的 reports、data、state 和 index.html；失败上传私有诊断 artifact。Windows 定时同步使用 git pull --ff-only，禁止覆盖本地改动。

## 验证与限制

单元及离线集成测试覆盖四类采集、时间边界、链接限制、事件去重、模型输出、费用、HTML 转义、发布恢复、重跑和失败。无 OPENAI_API_KEY 时不进行付费调用或制造真实日报；提供真实公开来源采集检查。仓库远端由用户指定后连接。
