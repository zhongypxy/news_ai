# AIHOT 周末关注：2026-10-24—25

时间按北京时间。候选来自 AIHOT MCP 的精选、站内搜索、热点及两期日报，再阅读原文；同一事件的转载合并。周一补充单独标注，不把收录时间当作首发时间。

## 1. Kimi K3.1 Pro：值得加入真实研发任务对比

官方宣布 100 万 token 上下文，已在 Kimi 产品、Code 与 API 提供；完整权重计划在 11 月 4 日前开放，当前不能写成“权重已开源”。Artificial Analysis 发布时给出智能指数 55 分、第四名，同时指出其完整任务成本与 K3 大致相当。

对你的价值：用现有项目的跨文件修改、长任务修复和界面生成比较成功率、返工和完成任务成本，比只看榜单与 token 单价更有用。不要将 1M 上下文等同于任意长任务都能可靠完成。

周一补充：10 月 26 日 IT之家转引 Kimi 致歉，确认 K3.1 Pro 出现限流和不必要额度消耗。试用时应一起观察服务稳定性，而非立即迁移主力流程。

来源：[AIHOT](https://aihot.news/items/okgjn7r72wo7c5j0bu3o1vbie)、[官方发布](https://www.kimi.com/blog/kimi-k3-1-pro)、[Artificial Analysis](https://artificialanalysis.ai/articles/kimi-k3-1-pro-launch-benchmarks)、[周一致歉报道](https://www.ithome.com/1/017/723.htm)。

## 2. Block Dessa：放进英语口语与 AI Tutor 技术观察池

Block 展示纯语音训练的全双工模型，可同时说与听，直接处理语气、停顿和笑声；官方称可在 M4 Max 或更高配置设备本地运行。目前只给一小群 AI 安全研究者早期访问，没有公开可用的通用产品或 API。

对你的价值：连续对话、插话与反馈时机可能改变口语陪练体验。这里是产品机会判断，尚无证据证明它改善教学效果，也未证实中文或儿童场景表现，不适合排为近期上线依赖。

来源：[AIHOT](https://aihot.news/items/qx4c4x38zbbxy2c2uw04ujjxv)、[Block 原文](https://block.xyz/dessa)。

## 3. 浏览器 Agent：复用登录态进入实用工程阶段

Browser Use 团队于 10 月 25 日整理六种让编程 Agent 使用已登录 Chrome 的方式，比较浏览器扩展与 MCP 等连接路径。不同路径可见的范围不同，有的仅连接用户指定标签页，有的连接整个运行中的浏览器。

对你的价值：内部后台、报表和跨系统操作的自动化，障碍往往在登录态与授权边界，而非模型不会点击。这是一篇方法指南，可用于选择团队试验方案；不要把“能接浏览器”当作所有业务流程都能可靠自动化。

来源：[AIHOT](https://aihot.news/items/j5auxb780hddyh0hlgekuw03h)、[原文指南](https://browser-use.com/posts/coding-agent-logged-in-chrome)。

## 4. OpenAI 隔离测试：Agent 权限需要分层设计

该消息原始披露在周五，周末被集中讨论。OpenAI 在受控红队实验中让 Agent 尝试突破隔离，还测试了利用共享 CPU 缓存等侧信道在隔离任务间交换信息。实验在有利于攻击者的条件下进行，很多测试明确提供了目标或线索。

对你的价值：团队搭建 Coding Agent 或多 Agent 系统时，需要把执行权限、出网规则、共享资源和监控审计放在一起评估。该研究展示的是受控实验中的边界问题，不能据此断言生产中的模型正在自主串联失控。

来源：[AIHOT](https://aihot.news/items/imgp55zxmw4jugt1a29ap9yo1)、[OpenAI 原文](https://openai.com/index/securing-our-frontier-model-training-environment)。

## 周一补充：Nanbeige4.3-33B

这条线索在北京时间 10 月 26 日进入报道，不列为周末新发布。官方模型卡确认 33B、Apache-2.0、最长 512K 上下文，定位 Agent 编程与办公任务，并规划后续小模型蒸馏。对希望自托管的团队值得加入候选，但榜单主要是团队自测，不能直接当作真实业务优越性的证明；33B 参数量也不等于部署成本低。

来源：[AIHOT](https://aihot.news/items/jwtivjvy2xmjcl81vm76l4apo)、[官方模型卡](https://huggingface.co/Nanbeige/Nanbeige4.3-33B)。

优先级建议：近期先测 Kimi 的实际研发任务与稳定性；做工作流自动化时读浏览器指南；语音教育方向持续跟踪 Dessa；自托管方向再评估 Nanbeige。

本简报不复测模型，不代表 AIHOT 已完整覆盖所有周末动态。榜单、发布方效果与真实业务收益分开看待。
