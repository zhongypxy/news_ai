# V2 实施计划

**Goal:** 实现可以实际运行、失败可追踪的全球 AI 每日情报采集与归档系统。
**Architecture:** 配置驱动采集 → 日期与来源校验 → 结构化 AI 编辑及核验 → 跨期事件去重 → 可恢复发布 → GitHub 归档 → Windows 同步。
**Tech Stack:** Python 3.11+、OpenAI Responses、Pydantic、HTTPX、Jinja2、pytest、GitHub Actions。

1. [ ] 目录、来源与运行配置、数据模型、HTTP 安全边界、RSS/API/发布页接口；先编写基础测试，运行失败再实现，运行通过后提交阶段一。
2. [ ] 固定报告窗口、Web Search、结构化编辑、重大新闻复核、事实支持校验、URL/事件/新进展去重、来源覆盖质量门；测试去重及失败路径，提交阶段二。
3. [ ] 内嵌 HTML 搜索/筛选/深色模式、历史首页、不可覆盖的可恢复发布事务、重复执行；验证转义和完整性，提交阶段三。
4. [ ] Actions 主调度与兜底、失败 artifact、自动提交、Windows 同步及任务安装、README；测试配置及脚本，提交阶段四。
5. [ ] 全套测试与质量检查、真实公开来源探测；API Key 授权且可用时真实端到端运行，否则列出明确未验证部分；提交最终验证记录。

各阶段在本聊天顺序执行。采用当前空目录，初始化独立本地仓库，避免影响其他项目。API Key 仅通过环境变量或 repository secret 注入。
